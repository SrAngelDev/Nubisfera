🌦️ Acerca de Nubisfera

Tu fuente moderna y fiable para consultar el tiempo en cualquier parte del mundo.

¿Qué es Nubisfera?

Nubisfera es una aplicación web moderna que proporciona información meteorológica detallada de cualquier ciudad del mundo, utilizando los datos de Open-Meteo, una API meteorológica gratuita y de código abierto con cobertura internacional.

✨ Características

🔍

Búsqueda Global

Busca y consulta el tiempo en cualquier ciudad del mundo con búsqueda instantánea

🌡️

Predicción Detallada

Hasta 7 días de predicción con datos horarios y temperaturas máximas/mínimas

⚡

Sistema de Caché

Carga instantánea de datos previamente consultados

🎨

Interfaz Moderna

Diseño dark mode profesional con animaciones fluidas

🛠️ Tecnologías

Angular 20.3 TypeScript 5.9 Open-Meteo API RxJS 7.8

📚 Propósito Educativo

Este proyecto ha sido desarrollado con propósitos exclusivamente educativos para aprender y practicar Angular 20, Standalone Components, programación reactiva con RxJS, y diseño responsive moderno.
